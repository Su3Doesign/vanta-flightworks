# Vanta Flightworks

A flight-helmet maker's site. A worn helmet hangs in front of the words and turns like a part on an inspection stand
as the page scrolls, with a heading readout that follows it.

Serve the folder over HTTP (`npx serve .`). three.js 0.169 loads from jsDelivr.

Helmet model: theblueturtle_, CC BY-NC 4.0, rebuilt for glTF by ctxwing, CC BY 4.0 (Khronos glTF Sample Assets).
Non-commercial: fine for a portfolio; replace the model before any paid use.
